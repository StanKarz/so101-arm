# so101-arm

SO-101 leader and follower arms running on LeRobot, plus the scripts I needed to get them there: motor setup, calibration and camera checks.

Teleoperation has worked since 29 Oct 2026. Next up: record demos, train ACT and measure it over 20 trials. Session notes are in `LOG.md`.

Run anything with `uv run python <script>.py`. Each script's docstring has its usage.
